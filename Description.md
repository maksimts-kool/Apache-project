# Дизайн и структура веб-приложения KawaiiEmoji

> Стиль: аниме/кавай — яркие акцентные цвета, скруглённые углы, игривая типографика, лёгкие тени и микро-анимации.

## Цветовая схема и типографика (глобально)

| Назначение | Цвет |
|---|---|
| Primary | `#FF6B9D` (розовый) |
| Secondary | `#A78BFA` (лавандовый) |
| Accent | `#FCD34D` (жёлтый) |
| Background | `#FFF0F6` (очень светло-розовый) |
| Surface | `#FFFFFF` |
| Text primary | `#1F1235` |
| Text muted | `#9CA3AF` |
| Error | `#F87171` |
| Success | `#34D399` |

**Типографика:**
- Заголовки: `Nunito` (жирный, скруглённый), 32/24/20/16px
- Тело: `Inter`, 14/16px
- Эмодзи-лейблы: `Noto Color Emoji` как fallback

**Скругление:** `border-radius: 16px` для карточек, `12px` для полей, `999px` для кнопок-пилюль и тегов.

## 1. Главная страница

### Header

```
┌─────────────────────────────────────────────────────────────────┐
│  🌸 KawaiiEmoji          [Поиск................🔍]   Войти  Рег │
│  (логотип + название)                             (или аватар)  │
└─────────────────────────────────────────────────────────────────┘
```

- Высота: `64px` на desktop, `56px` на mobile
- Фон: `#FFFFFF` с `box-shadow: 0 2px 12px rgba(255,107,157,0.12)`
- Логотип: иконка-сакура + текст, `font-size: 22px`, `font-weight: 800`
- **Поиск** — центр хедера, `width: 360px`, placeholder `"Найди своего кавай..."`, иконка лупы справа внутри поля
- **Неавторизованный:** кнопки `Войти` (ghost) и `Регистрация` (filled primary) — pill-стиль, справа
- **Авторизованный:** аватар пользователя `36px` + дропдаун (`Мои эмодзи`, `Загрузить`, `Настройки`, `Выйти`) + иконка уведомлений `🔔` с badge-счётчиком

### Навигация (под хедером, sticky)

```
[✨ Все]  [⭐ Популярные]  [🆕 Новые]  [🎌 Кавай]  [👤 Пользовательские]  [🔒 Анонимные]
```

- Горизонтальный scroll на mobile, фиксированная строка на desktop
- Активная вкладка: pill с фоном `#FF6B9D`, белый текст
- Неактивная: прозрачный фон, текст `#9CA3AF`, hover → лёгкий розовый фон

### Hero-секция (только для неавторизованных)

- Высота `~320px`, градиентный фон `linear-gradient(135deg, #FFF0F6, #EDE9FE)`
- Анимированные плавающие эмодзи-символы на заднем плане (`(づ｡◕‿‿◕｡)づ`, `(◕‿◕✿)` и т.д.)
- Заголовок: `"Создавай. Делись. Кавай."`, `font-size: 40px`
- Подзаголовок: 2–3 строки описания приложения
- CTA-кнопки: `Начать бесплатно` (primary filled) + `Смотреть эмодзи` (secondary outline), gap `12px`

### Фильтры и сортировка

```
Показано: 1240 эмодзи         [Сортировка: Популярные ▼]  [🎨 Фильтры]
```

- Правый край контентной зоны
- Дропдаун сортировки: `Популярные / Новые / По алфавиту`
- Кнопка `Фильтры` открывает боковую панель (drawer) справа:
  - Категории (чекбоксы): Кавай, Аниме, Смешные, Грустные, Любовь, Еда…
  - Тип: Kawaii / Пользовательские / Анонимные
  - Автор (поиск по имени)
  - Кнопка `Применить` + `Сбросить`

### Галерея эмодзи

**Layout:**
- Desktop (≥1280px): `5` колонок
- Tablet (768–1279px): `3–4` колонки
- Mobile (<768px): `2` колонки
- `gap: 16px`, `padding: 0 24px`

**Карточка эмодзи:**

```
┌──────────────────────┐
│                      │
│   (づ｡◕‿‿◕｡)づ      │  ← превью, font-size ~32px или img
│                      │
│  Название эмодзи     │  ← font-size 13px, bold, обрезать в 1 строку
│  от @username  💾 42 │  ← muted, мелкий, иконка скачиваний
│  [Копировать] [♡ 12] │  ← кнопки действий
└──────────────────────┘
```

- Размер карточки: `~180px` ширина, `~200px` высота на desktop
- Превью: белый фон `#FAFAFA`, `border: 1px solid #F3E8FF`, скругление `12px`
- Hover-состояние: карточка поднимается (`transform: translateY(-4px)`), тень усиливается, появляется тонкая розовая рамка
- **Кнопки в карточке:**
  - `Копировать` — pill secondary, при клике меняется на `✓ Скопировано!` на `1.5s`
  - `♡` — иконка лайка, анимация bounce при клике, цвет → `#FF6B9D`
  - Для авторизованного автора: дополнительно `✏️` (редактировать) и `🗑️` (удалить) в правом верхнем углу карточки, появляются при hover

**Пагинация / скролл:**
- Бесконечный скролл с `IntersectionObserver`
- Скелетон-лоадер: 10 ghost-карточек с shimmer-анимацией при загрузке следующей страницы
- Кнопка `Вернуться наверх ↑` (FAB, розовый, `position: fixed`, правый нижний угол) появляется после скролла на `400px`

### Footer

```
🌸 KawaiiEmoji © 2026    О проекте  |  FAQ  |  Правила  |  Контакты
                        Сделано с ♥ командой Hussein, Timur, Maksim, Nikita L, Nikita G
```

- Фон `#1F1235`, текст белый/muted
- Высота `~80px`, центрированный контент

## 2. Страница логина

### Layout

- Фон страницы: градиент `#FFF0F6 → #EDE9FE` + паттерн мелких эмодзи-символов с `opacity: 0.06`
- Карточка формы: `width: 420px` (desktop), центр страницы вертикально и горизонтально
- Карточка: `background: #FFFFFF`, `border-radius: 24px`, `padding: 40px 48px`, `box-shadow: 0 8px 40px rgba(167,139,250,0.18)`

```
         🌸 KawaiiEmoji
       Добро пожаловать!
    Войди и создавай кавай ✨

  ┌────────────────────────┐
  │ 👤  Email или никнейм  │
  └────────────────────────┘

  ┌────────────────────────┐
  │ 🔒  Пароль         👁️ │
  └────────────────────────┘

              Забыл пароль?

  ┌────────────────────────┐
  │      Войти  🌸         │
  └────────────────────────┘

  ─────── или ───────

  [G] Войти через Google

  Нет аккаунта? Зарегистрируйся
```

### Поля ввода

- `height: 52px`, `border-radius: 12px`, `border: 2px solid #E5E7EB`
- Placeholder-цвет: `#D1D5DB`
- Focus: `border-color: #FF6B9D`, `box-shadow: 0 0 0 4px rgba(255,107,157,0.12)`
- Иконка `👁️` в поле пароля — toggle видимости (клик меняет `type=password` ↔ `type=text`)

### Валидация

| Триггер | Поведение |
|---|---|
| Blur поля (уход фокуса) | Inline-ошибка появляется под полем |
| Submit с пустыми полями | Все поля подсвечиваются красным одновременно |
| Неверный пароль (ответ сервера) | Toast-уведомление сверху справа: красный, `"Неверный email или пароль"` |

- Inline-ошибка: `font-size: 12px`, цвет `#F87171`, иконка `⚠️` слева, `margin-top: 4px`
- Граница поля при ошибке: `border-color: #F87171`, `box-shadow: 0 0 0 4px rgba(248,113,113,0.12)`
- Toast: `position: fixed`, top-right, auto-hide `4s`, анимация slide-in

### Состояния кнопки «Войти»

| Состояние | Вид |
|---|---|
| Default | Розовый `#FF6B9D`, белый текст, тень |
| Hover | `#FF5C91`, `transform: translateY(-1px)`, усиленная тень |
| Active | `#E8527F`, `transform: translateY(0)` |
| Loading | Spinner-иконка слева + `"Входим..."`, `opacity: 0.85`, pointer-events off |
| Disabled | `#E5E7EB` фон, `#9CA3AF` текст, cursor not-allowed |

### Адаптивность

- **Desktop:** карточка `420px`, вертикальный центр через `min-height: 100vh`
- **Tablet (≤768px):** карточка `90vw`, `padding: 32px 32px`
- **Mobile (≤480px):** карточка на всю ширину без скруглений снизу или `100vw`, form layout без изменений, кнопка на всю ширину карточки

## 3. Страница загрузки и редактирования эмодзи

### Layout (двухколоночный на desktop)

```
┌─────────────────┬──────────────────────────────┐
│                 │                              │
│   ПРЕВЬЮ        │   ФОРМА МЕТАДАННЫХ           │
│   (live)        │                              │
│                 │                              │
└─────────────────┴──────────────────────────────┘
```

- Левая колонка: `40%` — превью + зона загрузки
- Правая колонка: `60%` — поля формы
- На tablet/mobile: одна колонка, превью сверху

### Зона загрузки (левая колонка)

**Состояние по умолчанию (пустое):**

```
┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┐
│                       │
│    🖼️                  │
│  Перетащи файл сюда   │  ← dashed border 2px, #D1D5DB
│  или нажми для выбора │
│                       │
│  PNG, GIF, SVG · до 2MB│
└─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┘
```

- `border: 2px dashed #D1D5DB`, `border-radius: 16px`, `min-height: 240px`
- Drag-over состояние: `border-color: #FF6B9D`, фон `#FFF0F6`, иконка увеличивается с анимацией
- Клик → открывает `<input type="file" accept="image/png,image/gif,image/svg+xml">`

**Состояние с загруженным файлом:**

```
┌──────────────────────┐
│                      │
│   (◕‿◕✿)             │  ← превью изображения или крупный эмодзи-текст
│                      │
│  emoji_name.png      │
│  124 KB      [✕]     │  ← кнопка удалить
└──────────────────────┘
     [Заменить файл]
```

- Реальный превью изображения через `FileReader API` / `URL.createObjectURL`
- Для текстовых (символьных) эмодзи: live-рендер из поля `символы` ниже

**Текстовая альтернатива:**

```
  — или введи символы вручную —

  ┌────────────────────────────────┐
  │ (づ｡◕‿‿◕｡)づ                   │  ← textarea, monospace
  └────────────────────────────────┘
  Превью: (づ｡◕‿‿◕｡)づ   ← живое обновление
```

### Форма метаданных (правая колонка)

```
Название эмодзи *
┌────────────────────────────────┐
│ Например: Обнимашки кавай      │  ← max 40 символов, счётчик справа
└────────────────────────────────┘

Теги
┌────────────────────────────────┐
│ [кавай ✕] [обнимашки ✕]  +... │  ← pill-теги с input внутри (tagify)
└────────────────────────────────┘
  Нажми Enter для добавления · макс. 10 тегов

Категория *
┌────────────────────────────────┐
│ ▾ Выбери категорию             │  ← select/dropdown
└────────────────────────────────┘
  [✨ Кавай] [🎌 Аниме] [😂 Смешное] ...  ← или chip-группа

Описание (необязательно)
┌────────────────────────────────┐
│                                │  ← textarea, 3 строки
│                                │
└────────────────────────────────┘
  0 / 200 символов

☐ Опубликовать анонимно
  (твоё имя не будет показано)

┌────────────────────────────────┐
│     Опубликовать эмодзи 🌸     │  ← primary button, full width
└────────────────────────────────┘
      Или сохранить как черновик
```

### Режим редактирования

**Отличия от создания:**

| Элемент | Создание | Редактирование |
|---|---|---|
| Заголовок страницы | `"Загрузить эмодзи"` | `"Редактировать эмодзи"` |
| Зона загрузки | Пустая | Показывает текущее изображение |
| Кнопка изображения | — | `"Заменить изображение"` |
| CTA-кнопка | `"Опубликовать 🌸"` | `"Сохранить изменения ✓"` |
| Доп. кнопка | `"Черновик"` | `"Удалить эмодзи 🗑️"` (destructive, outline red) |
| Чекбокс анонимности | Доступен | Заблокирован (нельзя сменить после публикации), tooltip с объяснением |

- Форма предзаполнена текущими значениями
- Поле символов разблокировано для правки
- Замена изображения опциональна: если не тронуть — остаётся старое

### Обработка ошибок и прогресс загрузки

**Прогресс-бар** (при загрузке файла):

```
Загружаем...  ████████░░░░  65%
```

- Полоска под зоной загрузки, цвет `#FF6B9D` → `#34D399` при завершении
- Анимация заполнения, `border-radius: 999px`

**Ошибки файла** (inline, под зоной):

- `"Файл слишком большой. Максимум 2MB"` — красный текст + иконка
- `"Формат не поддерживается. Используй PNG, GIF или SVG"` — аналогично

**Успешное сохранение:**

```
┌─────────────────────────────────────────────┐
│  ✅  Эмодзи опубликован!                     │
│  Посмотреть в каталоге → или Загрузить ещё  │
└─────────────────────────────────────────────┘
```

- Toast или inline-баннер зелёного цвета `#34D399`, появляется сверху с анимацией slide-down
- Две ссылки-действия после успеха

### Адаптивность

| Breakpoint | Layout |
|---|---|
| Desktop ≥1024px | Двухколоночный, `40/60` split |
| Tablet 768–1023px | Одна колонка, превью `280px` по центру, форма под ним |
| Mobile <768px | Одна колонка на всю ширину, `padding: 0 16px`, кнопки `width: 100%` |
